FrozenCal-K

Lightweight preference calibration for image-edit evaluation. QwenVL-Embedding-2B and SigLIP2 stay frozen while a small K-adaptive head learns how to rank edits for a target preference distribution.

What the method does

FrozenCal-K combines 12 absolute signals with 12 within-group relative signals and uses separate heads for K=2, K=3, and K=4. This adapts an evaluator without repeatedly fine-tuning a large reward model.

Reproducibility

Calibration and benchmark embedding files are hosted on ModelScope. The GitHub repository contains feature construction, training, and cached inference code; the online playground accepts source images, an editing instruction, and edited candidates.

Reported numbers use the held-out 70% reporting split described in the paper. The online demo performs image-side feature extraction before applying the released head.
