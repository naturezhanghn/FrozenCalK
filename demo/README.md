# FrozenCal-K online demo

This lightweight Gradio app applies the released K-specific FrozenCal-K heads to
12-dimensional frozen feature vectors. It is intended for an interactive check
of the ranking mechanism, not for extracting QwenVL/SigLIP2 features in the
browser. The full cached benchmark inference remains in the parent repository.

Run locally with `pip install -r requirements.txt && python app.py`.
